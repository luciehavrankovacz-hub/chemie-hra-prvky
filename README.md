# Chemie – hra: Periodická soustava prvků

Výuková hra na procvičování periodické tabulky. Vytvořila Lucie.

**Hrát online:** https://luciehavrankovacz-hub.github.io/chemie-hra-prvky/

## Co hra umí
- celá tabulka **118 prvků** s českými názvy, barvy podle skupin (kovy, nekovy, halogeny, vzácné plyny…)
- **3 režimy:** značka → český název · český název → značka · učení (jen prohlížení)
- zelená ✓ fajfka za správnou odpověď, červený ✕ křížek za chybu přímo v okénku
- rozsahy: prvních 20 / 36 / 56 prvků, hlavní skupiny, celá tabulka
- body, série správných odpovědí, časomíra, nápověda, náhodné pořadí, zvuky
- na konci **vysvědčení se známkou 1–5** a možnost trénovat jen chyby

Odpovědi se porovnávají bez diakritiky a velikosti písmen (`zelezo` = `Železo`).

## Jak hru upravit
Zdroj je jediný soubor `index.html` (HTML + CSS + JavaScript, žádné knihovny, funguje i offline).
Pracovní kopie je na ploše: `Desktop\Moje tvorba\Chemie-hra-periodicka-tabulka.html`.
Po úpravě zkopíruj na ploše upravený soubor sem jako `index.html` a udělej `git push`.
